Search

Endpoint de búsqueda de ejemplo. Úsalo como base para conectar tu propia fuente de resultados.

GET /api/search

Busca videos de YouTube. Requiere tu API key, ya sea como parámetro apikey o como header apikey.

Parámetro Tipo Requerido Descripción
query string Sí Texto a buscar
apikey string Sí Tu API key personal 
GET /api/search?query=ejemplo&apikey=TU_API_KEY
