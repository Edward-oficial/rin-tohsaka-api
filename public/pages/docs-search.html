Search

Endpoint de búsqueda de ejemplo. Úsalo como base para conectar tu propia fuente de resultados.

GET /api/tools/search

Requiere tu API key, ya sea como parámetro apikey o como header apikey.

ParámetroTipoRequeridoDescripción
qstringSíTexto a buscar
apikeystringSíTu API key personal
 
GET /api/tools/search?q=ejemplo&apikey=TU_API_KEY
